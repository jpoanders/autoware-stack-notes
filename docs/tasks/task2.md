Study the researcher-provided C++ LSEU implementation and list of specifications. Jointly define how the existing LSEU code will interact with ROS 2, CycloneDDS, Autoware topics, tracepoints, configuration files, and experiment-control components.
The students will produce an interface specification before implementing adapters or integration code.
Step 1 — Review the C++ code and specification
Step 2 — Implement actuation/Monitoring interface
Task 2 is complete when:

      
 The C++ LSEU API has been reviewed.   
      
 All interface assumptions are documented.   
      
 The monitored-event structure is defined.   
      
 Adapters for the four monitored topics are defined.   
      
 Timestamp and clock semantics are documented.   
      
 The ROS 2 component architecture is defined.   
      
 The verdict-message format is approved.   
      
 The configuration schema is approved.   
      
 Custom tracepoints are defined.   
      
 Error and shutdown behavior is defined.
